# moxxmpp

A pure-Dart XMPP library.

The TCP transport (RFC 6120 and XEP-0368) is `package:moxxmpp/socket_tcp.dart`.
It stays out of the main library because it imports `dart:io`.

Documentation is available [here](https://docs.moxxy.org/moxxmpp/index.html).
